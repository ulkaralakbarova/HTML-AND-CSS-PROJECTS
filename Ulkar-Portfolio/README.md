# HTML and CSS Projects

## Projects

- [Portfolio Website](./Ulkar-Portfolio/)
- [Ulkar Academy Movie Theatre Site](./Academy-Cinemas/)
- Basic HTML Website
- One-Page Website

### Portfolio Website

This is my personal professional portfolio. It was created with HTML and CSS and includes Home, About, Projects, GitHub and Contact sections. The site uses responsive layouts, custom colors, animations and hover effects so it works on desktop and mobile screens.

### Ulkar Academy Movie Theatre Site

This is a movie-theatre home page styled with CSS and Bootstrap. It includes responsive navigation, movie content and Bootstrap components including a footer.

### Basic HTML Website

This project demonstrates foundational HTML elements, page structure, links, images and semantic content.

### One-Page Website

This single-page project contains navigation, image, contact and footer sections organized with HTML and styled with CSS.

### Creating CSS Effects

This exercise demonstrates visual styling and interactive CSS effects such as hover behavior, transitions and image presentation.
